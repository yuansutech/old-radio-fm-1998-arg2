Phase 1: Getting to know Night Ferry

1-1
index.html → home.html

You learn the station is called “Night Ferry,” and host Su Wan disappeared on March 17, 1998. Sound engineer Lu Chen saved everything.

1-2
about.html

Lu Chen says: 3 number fragments — listener letters, host profile, missing person file.

Phase 2: Collecting the three fragments

2-1
letters.html → 0214

Premiere date, February 14, 1998 → 0214. Use it to unlock broadcast-03.html.

2-2
host.html → 9870

Su Wan's interview keeps mentioning the frequency 98.7. Read “98.7” backwards, and you get 9870. Use it to unlock terminal.html.

Note: This is the trickiest point in the game — the password is not the frequency itself, but the frequency's digits read in reverse.

2-3
missing.html → 0317

Date of disappearance, March 17, 1998 → 0317. Used for verification in decode.html.

Phase 3: Unlocking

3-1
index.html → broadcast-03.mp3

Enter 0214. Read Su Wan's final episode, which never aired.

3-2
index.html → terminal.html

Enter 9870. Enter the terminal.

3-3
In the terminal, type unlock 9870

✅ Output: Password correct. final.txt has been decrypted. Unlocks the ending.

Phase 4: The ending

4-1
index.html → final.html

Read Su Wan's last voice. Game complete.
